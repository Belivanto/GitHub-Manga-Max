## Ep.5 การล้างแค้น

จิ้งจอกได้ลุกขึ้นสู้อีกครั้งพร้อมกับ“พลังแห่งโลกคู่ขนาน” — 
พลังที่เชื่อมเส้นเวลา—เขารู้ว่าใช้พลังแต่ต้องแลกกับชีวิต
แต่เขาก็ต้องการใช้มันเพื่อล้างแคนแล้วนำบอสกลับ
คืนมาแม้แต่ต้องแลกกับชีวิตตัวเอง จิ้งจอกนั้นได้ใช้ พลังที่เชื่อมเส้นเวลา
กลับมาใน time-line ตอนที่บอสมีชีวิตอยู่ใน วันที่เกิดเหตุการณ์
เขาได้เห็นโลกคู่ขนานอันมากมายที่ได้พบเจอว่าเหตุการณ์ที่บอสรอดหรือตาย
แล้วเขาได้กลับเจอบอสแล้ววววว
